# Talha Edu Website

Official website of **Talha Edu** – Empowering Learning. Inspiring Tomorrow.

Talha Edu is an educational technology initiative focused on creating a smarter and more accessible learning experience through modern digital solutions.

## Features shown on the site
- Study Mode
- Reels Blocker
- App Block
- App Limit
- Apps Hub
- Progress Tracking and Study Streak
- Reminders

## Built with
HTML, CSS and JavaScript (no frameworks, no dependencies).

## Project structure
- `index.html` – main page
- `css/style.css` – styles
- `js/main.js` – interactions and site settings
- `assets/images/` – app screenshots and developer photo
